What is Nex Editor?
Overview and purpose

Nex Editor is a built-in tab inside TurboFPS Pro that lets you change the graphics and gameplay settings of BGMI and PUBG Mobile beyond what the game normally allows — things like unlocking higher FPS, changing visual quality, color style, brightness, and gyroscope behavior.

All changes are applied directly to the game. No root is needed. You just import your game's settings, make your changes, and hit Apply.

Supported Games
BGMI (India) · PUBG Mobile Global · PUBG Mobile Korea · PUBG Mobile Vietnam · PUBG Mobile Taiwan

Mode Selector
Choose whether to edit in-match, lobby, or both

Next to the game chips you'll find three buttons: Mixed, Combat, and Lobby. This controls which part of the game your changes apply to.

MixedBoth at once
CombatIn-match only
LobbyMain menu only
ModeWhat gets changed
MixedYour changes apply to both the in-match experience and the lobby at the same time. This is the recommended mode for most users.
CombatOnly your in-match (battle) settings change. The lobby looks exactly the same as before.
LobbyOnly your lobby (main menu) settings change. In-match settings stay untouched.
Want different styles for match vs lobby?
Turn on the Custom Style (Color) switch in the FPS & Graphics tab. Then use Combat mode to set one color style and Lobby mode to set a different one. When this switch is off, both stay the same.

Advanced Tab
For users who want to go deeper

The Advanced tab shows a full list of every setting inside your game's file. Think of it as a complete settings panel where nothing is hidden. Most users won't need to touch this — the FPS & Graphics tab covers the important ones — but it's here if you want more control.

8.1 Search

Type in the search bar at the top to filter the list by name. A count below shows how many settings are visible. If nothing matches, an empty state message appears.

8.2 How to Edit a Setting

Each setting appears as a card showing its name and current value. There are two types:

Extreme+ (90 FPS)

Value settingTap the card or the edit icon. A sheet opens where you pick from a list of options (for settings with fixed choices) or type in a value manually.

Long-press to remove a setting
Long-pressing a card opens a confirmation to remove that setting from the file entirely. The game will regenerate a default value for it the next time it starts. Only do this if you know what you're removing — it can't be undone from the editor (use Reset App Changes to recover).
Stays in sync
Whatever you change here is immediately reflected in the FPS & Graphics tab, and vice versa. Both tabs always show the same data.

Applying Settings to Your Game
How to make your changes actually take effect
  • 1
    Make your changes in the FPS & Graphics tab.
  • 2
    Make sure the correct game chip is selected at the top (e.g. INDIA for BGMI).
  • 3
    Fully close your game — swipe it away from Recent Apps.
  • 4
    Tap the Apply button. A confirmation dialog will appear.
  • 5
    Confirm by tapping Apply again. Free users will see a short ad first; Pro users skip straight to applying.
  • 6
    A success message appears when done.
  • 7
    Open your game — your new settings are now active.
Don't forget to Apply!
Changes you make in the editor do not automatically go to your game. You must tap Apply every time. If you close TurboFPS Pro without tapping Apply, your edits are lost.
Apply not working?
Check three things: (1) Shizuku is running — open the Shizuku app to confirm. (2) Your game is fully closed. (3) The correct game chip is selected. If it still fails, use the Save button to export the file and place it manually.

Reset Options
Two different ways to reset — know the difference

Tap the three-dot menu at the top right and select Reset. You'll see two options:

Reset App Changes
Undoes any edits you've made in this session and takes the editor back to the state it was in when you last imported or opened a file. Nothing is written to the game — it's completely safe. Use this if you made a mistake and want to start over.
Reset Game File
Completely deletes the settings file from your game. The next time you open the game, it will create a brand new default settings file from scratch. Use this only if you want to fully factory-reset your game's graphics settings.
Reset Game File removes everything
This doesn't just reset graphics — it deletes the entire settings file, which also includes things like your in-game sensitivity, crosshair settings, and control layout. Only use it if you're sure you want a completely fresh start.

Quick Start
Unlock FPS in under 2 minutes
  • 1
    Open Shizuku and make sure it shows Running.
  • 2
    Open TurboFPS Pro and go to the Nex Editor tab.
  • 3
    Tap the Import button and select your game version to load your current settings.
  • 4
    In the FPS & Graphics tab, tap your desired FPS — e.g. Extreme+ for 90 FPS.
  • 5
    Pick a graphics quality — e.g. Balanced for a solid middle ground.
  • 6
    Fully close your game, then tap the Apply button and confirm.
  • 7
    Open your game and enjoy the new settings.
