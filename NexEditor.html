What is Nex Editor?
Overview and purpose

Nex Editor is a built-in tab inside TurboFPS Pro that lets you directly read and write the Active.sav file used by BGMI and PUBG Mobile. This file stores every graphics and gameplay setting — FPS level, quality, style, brightness, gyroscope mode, and many more properties.

Instead of being limited to what the in-game settings screen exposes, Nex Editor lets you change values the game normally hides or caps — like unlocking higher FPS tiers, custom frame rates from 15 to 165, or different quality settings per mode.

Supported Games
BGMI (India) · PUBG Mobile Global · PUBG Mobile Korea · PUBG Mobile Vietnam · PUBG Mobile Taiwan

Mode Selector
Mixed · Combat · Lobby — controls which SAV properties are written

To the right of the game chips row is a compact three-button toggle. This controls which game context your edits apply to.

MixedBoth at once
CombatBattle / match only
LobbyMain menu only
ModeProperties written
MixedFPS writes to FPSLevel, BattleFPS, LobbyFPS, MainCityFPS. Quality/style writes to both Battle and Lobby keys. Recommended default.
CombatFPS writes to BattleFPS + MainCityFPS. Quality writes to BattleRenderQuality. Style writes to BattleRenderStyle.
LobbyFPS writes to LobbyFPS + MainCityFPS. Quality writes to LobbyRenderQuality. Style writes to LobbyRenderStyle.
Custom Style (Separate Config)
The Custom Style (Color) switch in the FPS & Graphics tab enables HasGraphicsSeparateConfig. When ON, Combat and Lobby style are independent — use Combat/Lobby mode to set them differently. When turned OFF, Lobby style automatically syncs to match Combat.

Advanced Tab
Raw SAV property editor with search and delete

Shows every readable property in the loaded SAV. Known properties (FPSLevel, BattleRenderQuality, etc.) appear first in a fixed order. All remaining properties follow.

8.1 Search Bar

Filters the list in real time by property name. A count label below shows how many results match — e.g. "32 settings". An empty state message appears if nothing matches.

Two-way sync
Changes in Advanced instantly update the FPS & Graphics tab controls, and vice versa. Both views always reflect the same underlying data.

Applying Settings to Your Game
The full Apply flow step by step
  • 1
    Make your changes in the FPS & Graphics tab.
  • 2
    Confirm the correct game chip is selected (e.g. INDIA for BGMI).
  • 3
    Fully close the game — force-stop it from Recent Apps.
  • 4
    Tap the Apply FAB. A dialog appears: "Apply to [Game]? Make sure [Game] is fully closed."
  • 5
    Tap Apply in the dialog. Free users watch a short rewarded ad; Pro users skip it.
  • 6
    The SAV is written to the game's directory via Shizuku shell. Toast shows: "Applied successfully!"
  • 7
    Open the game — your new settings are now active.
Changes are NOT automatic
Editing values in any tab does not immediately write to the game. You must tap Apply every time. If you close TurboFPS Pro without applying, in-memory changes are lost.
Apply failed? Check these
(1) Shizuku must be running — open Shizuku app to verify. (2) Game must be fully closed. (3) Correct game chip must be selected. You can also use Save to export the file and copy it manually.

Reset Options
Two distinct resets — editor state vs game file on device

Open via the three-dot menu → Reset. A bottom sheet shows two options:

Reset App Changes
Undoes all unsaved edits in the current session. Restores the editor to the state it was in when you last opened or imported the file. Nothing is written to the game. If no changes were made, it simply reloads from the last imported state.
Reset Game File
Deletes the Active.sav from the selected game's storage on your device using Shizuku shell. The game auto-generates a fresh default file on next launch. Requires Shizuku + game must be closed.
Reset Game File is permanent
This deletes all custom settings stored in Active.sav — including in-game sensitivity, crosshair colour, control layout, and everything else in that file. Only use it to fully restore the game to factory settings.

Quick Start
Unlock FPS in under 2 minutes
  • 1
    Open Shizuku and confirm it shows Running.
  • 2
    Open TurboFPS Pro → go to the Nex Editor tab.
  • 3
    Tap Import in the bottom action bar → select your game version.
  • 4
    In the FPS & Graphics tab, tap your desired FPS preset — e.g. Extreme+ for 90 FPS.
  • 5
    Select a quality preset — e.g. Balanced.
  • 6
    Fully close the game. Tap the Apply FAB and confirm.
  • 7
    Open the game — enjoy the new settings.
